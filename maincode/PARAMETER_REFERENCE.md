## 🔍 症状→参数对应表

快速找到应该调哪个参数。

### 症状: 船体振荡不稳

```
优先级 1 (最快) : 降低 PID_KP
  PID_KP: 20.0 → 15.0
  重新编译烧录后观察

优先级 2 (如果症状改善但未完全消失):
  ANGLE_DEADZONE: 1.0 → 2.0
  ANGLE_DEADZONE_SOFT: 3.0 → 4.0

优先级 3 (激进的滤波强化):
  ALPHA_EMA: 0.15 → 0.08
```

### 症状: 响应太慢，受扰后很久才恢复

```
优先级 1: 提高 PID_KP
  PID_KP: 20.0 → 25.0

优先级 2 (配合效果):
  PID_KI: 1.0 → 1.5

优先级 3 (缩小死区):
  ANGLE_DEADZONE: 1.0 → 0.5
```

### 症状: 持续一侧偏离，不能完全回正

```
优先级 1: 提高积分项
  PID_KI: 1.0 → 2.5

优先级 2 (持续无效):
  检查陀螺仪零偏 (日志中的 Gyro bias)
  或重新校准 IMU
```

### 症状: 看到持续的小抖动/噪声

```
优先级 1: 加强低通滤波
  ALPHA_EMA: 0.15 → 0.1

优先级 2 (如果滤波后响应变慢):
  同时调整: PID_KP: 20.0 → 22.0

优先级 3 (激进):
  降低加速度权重:
  ALPHA_ACC: 0.98 → 0.95
```

## 📊 参数调整的通用规则

### PID 参数

```
Kp (比例增益)
  作用: 对当前误差的直接响应
  调大: 响应快，但容易振荡
  调小: 响应慢，但稳定
  范围: 10.0 ~ 30.0

Ki (积分增益) 
  作用: 消除长期偏离
  调大: 偏离恢复快，但容易振荡
  调小: 稳定，但可能有余差
  范围: 0.2 ~ 3.0

Kd (微分增益)
  作用: 抑制振荡 (本项目中通常为 0)
  调大: 更平缓，但响应延迟
  调小: 响应快，但可能振荡
  范围: 0.0 ~ 1.0
```

### 死区参数

```
ANGLE_DEADZONE (核心死区)
  作用: 在此范围内完全不响应
  越大: 抖动减少，但对小扰动不敏感
  越小: 敏感，但容易因噪声触发
  范围: 0.5° ~ 3.0°

ANGLE_DEADZONE_SOFT (软死区)
  作用: 在此范围内平滑过渡
  越大: 响应更平缓
  越小: 响应更灵敏
  范围: 2.0° ~ 6.0°
  
  建议: DEADZONE_SOFT ≈ 3 × DEADZONE
```

### 融合参数

```
ALPHA_ACC (加速度权重)
  作用: 控制对加速度的信任程度
  越大 (接近 1.0): 更信任加速度，低频特性好
  越小: 更信任陀螺仪，短期稳定好
  范围: 0.95 ~ 0.99 (默认推荐 0.98)

ALPHA_EMA (低通滤波)
  作用: 数据平滑程度
  越大: 滤波较弱，噪声多但响应快
  越小: 滤波较强，平滑但可能有延迟
  范围: 0.08 ~ 0.25 (默认推荐 0.15)
```


## 🎯 推荐调参策略

### 方案 A: 快速稳定 (3 分钟)

适合: 系统能启动，但有明显振荡

```
第 1 步 (30 秒): 降低 Kp
  20.0 → 17.0
  
第 2 步 (30 秒): 增大死区
  DEADZONE: 1.0 → 1.5
  DEADZONE_SOFT: 3.0 → 4.0
  
第 3 步 (30 秒): 加强滤波
  ALPHA_EMA: 0.15 → 0.12
  
第 4 步 (观察 30 秒): 评估效果
```

### 方案 B: 精细调参 (10-15 分钟)

适合: 需要最优性能

```
第 1 步: 粗调 (方案 A 前两步)
第 2 步: 微调 Kp (±0.5 步进)
第 3 步: 微调 Ki (0.5 步进)
第 4 步: 微调死区 (0.2° 步进)
第 5 步: 微调滤波系数 (0.01 步进)
第 6 步: 长期观察 (1-2 分钟)
```

### 方案 C: 保守调参 (最稳定，最慢)

```
每次调整幅度: 10% 左右
每次观察时间: 30-60 秒
额外验证: 人工给船体施加扰动，观察恢复过程
```

## 💡 调参技巧和陷阱

### ✅ 正确做法
```
□ 每次只改一个参数
□ 给予系统足够的观察时间 (30 秒)
□ 记录每次的修改和效果
□ 从小幅度改变开始
□ 在系统相对稳定时进行微调
```

### ❌ 避免的做法
```
□ 同时改多个参数 (无法确定哪个有效)
□ 改完立即再改 (还没看清效果)
□ 大幅度改变 (容易过度调整)
□ 没有记录 (调不回来了)
□ 在极端不稳定时微调 (看不出效果)
```
