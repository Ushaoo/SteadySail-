# ESP32 MicroPython 项目依赖说明
# 此文件列出 ESP32 上需要的库和工具
#
# 注意: MicroPython 固件中大多数库已内置
# 本文件仅用于参考和说明

# ==================== 在开发电脑上需要安装的工具 ====================

# 固件烧录工具 (必需)
esptool>=3.0

# 串口通信 (必需，esptool 依赖)
pyserial>=3.5

# 文件管理工具 (推荐，用于上传代码)
mpremote>=0.4.0

# ==================== ESP32 MicroPython 内置库 (无需安装) ====================
#
# 硬件接口:
#   machine              - GPIO, I2C, PWM, UART, Timer, ADC等
#   micropython          - 内部优化函数
#
# 数据类型和集合:
#   array                - 数组
#   collections          - deque, namedtuple
#   json                 - JSON 解析 (内置)
#   struct               - 二进制数据打包
#
# 时间和系统:
#   time                 - 时间管理
#   math                 - 数学函数
#   random               - 随机数
#
# 网络和通信:
#   socket               - 网络通信
#   network              - WiFi 连接
#   ubluetooth           - 蓝牙支持
#
# 文件系统:
#   uos                  - 文件操作
#   usys                 - 系统参数
#
# 异步编程:
#   uasyncio             - 协程支持

# ==================== 项目中包含的驱动库 (需要上传到 ESP32) ====================
#
# 路径: esp32_new/lib/
#
# mpu6050.py           - MPU6050 IMU 传感器驱动
# pca9685.py           - PCA9685 PWM 扩展板驱动
# pid_controller.py    - PID 控制器实现
# imu_fusion.py        - 双 IMU 融合算法
# wifi_helper.py       - WiFi 连接辅助函数

# ==================== 开发电脑上的可选库 (用于数据处理) ====================
#
# 如果需要在 PC 上处理来自 ESP32 的数据:
#
